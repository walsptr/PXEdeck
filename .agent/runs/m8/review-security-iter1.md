## Diverifikasi aman
- **Password admin:** hanya prompt tersembunyi, `--admin-password-stdin`, atau file 0600/0400 non-symlink; `--admin-password`, key config `ADMIN_PASSWORD`, env `PXE_INSTALL_ADMIN_PASSWORD` ditolak; ke node lewat builtin `printf` via pipe (tidak di argv); `admin-hash.mjs`/`admin-verify.mjs` hanya stdin, tidak mencetak apa pun; `timingSafeEqual` pada buffer sama panjang + NFC (konsisten `password.ts`); hash dicek `SCRYPT_RE` sebelum dirender; variabel dibersihkan termasuk di trap.
- **File env:** `put_file` mktemp di direktori target (0600) → chmod 0640, chown `root:pxe`, `mv` atomik; bukti KVM `640 0:988`; salinan render di mktemp 0700; saat upgrade `PXE_INSECURE_NO_LEASE_CHECK` dipaksa 0 dan `_CONFIRM` dihapus.
- **Kepercayaan manifest:** direktori 0700 dan file 0600 milik root; cek pemilik (`$EUID`), group/other-write, symlink fail-closed, begitu juga baris invalid; `tree` hanya tepat `/opt/pxe-dashboard`; `rm` `file`/`link` tidak mengikuti symlink; `rm -rf --one-file-system` dan `chown -R` (`-P`) aman terhadap symlink yang ditanam user `pxe`. Tinggal pengecualian `..` (SR-8-1).
- **Rilis dan build:** `npm ci`/`next build` sebagai `pxe` dengan `env -i`; ekstraksi root `--no-same-owner`, proteksi delayed-symlink GNU tar, `chown -R root`; `.env*` dan `*.db` ditolak.
- **dnsmasq:** `interface=` + `bind-interfaces` dicek setelah render; `policy-rc.d` 101 mencegah start sebelum config; verifikasi gagal → dnsmasq dihentikan dan unit yang di-enable di-rollback; VLAN: probe setelah `netplan apply` sebelum dnsmasq, dnsmasq fail-closed bila interface tidak ada.
- **Probe DHCP:** socket UDP `SO_BINDTODEVICE` (bukan raw), hanya DISCOVER, nama interface divalidasi, `python3 -I`.
- **nginx dan `PXE_INSTALLER_LOCAL`:** klien PXE tidak bisa memakai IP server sebagai sumber TCP (martian, SYN-ACK dikirim lokal); `127.0.0.1` tidak cocok karena nginx hanya listen di `LISTEN_IPS`; `X-Real-IP` ditimpa `$remote_addr`, `X-Forwarded-*`/`Forwarded` dikosongkan.
- **Validasi input:** nama interface, IP/CIDR, domain, user, entri VLAN, path ISO, allowed hosts dengan regex ketat; karakter yang diizinkan tidak bisa memecah substitusi `sed`, YAML, baris fstab, heredoc; file config di-parse KEY=VALUE, tidak di-source.
- **Firewall:** opt-in, tabel `inet pxe_dashboard` sendiri, hanya `iifname $IFACE`, aturan lain tidak disentuh.
- **Uninstall `--purge`:** `userdel` (tanpa `-r`) hanya bila manifest mencatat installer membuat user.
- **Secret repo dan bukti:** `git grep` hash scrypt, `$6$`/`$y$`, `PRIVATE KEY`, private key OpenSSH, `/boot/<mac>/<token>`, cookie → tanpa kebocoran di `.agent/runs/m8/**`; `PXE_ADMIN_PASSWORD_HASH` hanya `<disamarkan>`; hit `ssh-ed25519` = public key host; `install-*-passfile.txt` hanya `600 root`; `evidence-scan-playwright.txt` bersih; `deploy/install.conf.example` dummy.
